Reporting guidelines in other languages

Many reporting guidelines have been translated, so that authors, editors, and reviewers can use them in their own language. On individual reporting guideline pags we have noted and provided a link to a translation. However, this page provides a central list translations of some key reporting guidelines.

Many of the translations listed below are hosted on an external website, such as the guideline developers’ own site or a journal.

We only list translations to the most recent reporting guidelines. So if a reporting guideline has been updated (i.e., PRISMA-2009 -> PRISMA-2020), we only list translations for the updated reporting guideline.

If you have translated a reporting guideline or are aware of one that we have not listed here please let us know. The EQUATOR Network does not translate reporting guidelines.

Translations are grouped by language. For each one you can see whether it is available as a:

  • PDF – a document to read or print.
  • Word – an editable document (.docx or .doc), useful for completing a checklist.
  • Web page – any other link, such as a journal article, repository record, or a download page on the guideline’s website.

Where a guideline has more than one translation file (for example a checklist and an explanation paper), each is listed separately.
